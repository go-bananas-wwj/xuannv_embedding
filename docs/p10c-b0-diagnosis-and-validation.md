# P10C 与 B0：问题诊断和验证计划

日期：2026-09-21。状态：完成证据复核和实验设计，未启动本计划的新训练或评测。
目标：检验旧 P10C 相对 B0 的区域制图优势，并区分数据、训练与导出因素。保留负结果，不预设胜出。

## 已知事实与尚待验证的原因

| 因素 | 旧 P10C | B0 / 本次高分 Transformer |
|---|---|---|
| 权重 | 生产第 800 Epoch | B0 验证损失选第 192 Epoch；Transformer 第 600 Epoch |
| 训练历史 | 日志确认从 P9B 第 800 Epoch 初始化，再训练 | B0 从零训练；Transformer 从 B0 冻结适配 |
| 区域 | 320 图块参与编码器训练和区域 OSM 辅助监督 | B0 与 Transformer 同为训练 158、验证 67、测试 57、缓冲 38 |
| 高分路径 | 先缩放至 10 m，再卷积，在月度表征末端融合 | B0 无高分分支；Transformer 按月在第 2、4 块后注入 |
| 优化 | 历史优化器包含主干参数 | Transformer 仅更新新增模块；基座、原监督头冻结 |
| 导出 | 5 月生产命令含扩边 16、中心裁切 128 | 当前 B0 / Transformer 逐块直接导出 |

PCA 显示旧 P10C 的局部纹理和建筑群内部对比更强，是待验证的细部表征优势，不等于地物精度已提高。不同训练范围、热启动历史和导出方式使该比较不能直接归因于高分融合。

最近 Transformer 的验证重建总损失明显下降，语义损失约 1.355→1.358，200→600 Epoch 的验证 MLP F1 只增加约 0.114 个百分点。这支持“重建改善尚未转化为下游收益”的诊断。冻结主干、10 m 重建目标可能限制收益，但尚不是被消融证明的原因；不能断言 Transformer 不适用或高分数据无效。

## 第一阶段：固定权重，先量化现有制品差异

1. **导出 2×2 对照**：P10C / B0 各做不扩边、每边扩 16 个 10 m 像素后裁回 128×128。使用真实相邻影像、统一地理范围/质量掩膜、同一月份；锁定源数据与处理记录。主比较为两者均扩边，普通导出仅分析接缝。5 月主月、4 月固定复核月；不根据成绩选月份。
2. **支持与读出配对**：四类为建筑、道路、水体、绿地；主读出 MLP，3×3 卷积与 kNN 固定复核。使用相同支持 ID、标签、空间划分、训练步数、阈值校准规则。先复用已有 5/10 完整图块预算，明确包含前景与背景；头在各自原始嵌入上重训，不跨模型套用头或使用 PCA 特征。
3. **重复与统计**：支持抽样种子预登记为 20260916、20260917、20260918，头种子固定 41，预算 5 是同种子预算 10 的子集。所有任务/预算/头全部报告。主终点为 5 图块、MLP 的四类宏 IoU，边界 F1@10 m 为预指定关键次终点；F1、AP、Boundary IoU、边界 F1@20 m 补充。
4. **正确解释旧标签**：OSM 结果仅为开发诊断和既有区域制品对照。P10C 见过 B0 留出区域及其 OSM 监督，不能称为两模型公平的未见区域泛化测试。当前测试数据已多次查看，不冒充新的盲测。

### 需要量化的优势

| 问题 | 指标与控制 |
|---|---|
| 四类能否更准确识别 | 每类 IoU/F1/AP，四类等权宏平均；不按像元数量让大面积绿地支配结果 |
| 边界是否真的更准 | Boundary F1@10 m、@20 m 与 Boundary IoU；同一标签、同一栅格化和 ignore 范围 |
| 小目标是否保留 | 按参考标签面积预分 ≤9、10–49、≥50 个 10 m 像元，分别报告召回、误检与 IoU；1像元以下目标单列不可判，不声称米级精度 |
| 道路是否连贯 | 固定参考中心线/节点上的连通率和断裂率，同时报告道路精确率；仅对参考可解析路段统计，避免粗化预测虚增连通性 |
| 拼接是否稳定 | 同一像素在移动推理窗口下的 64维余弦距离及下游概率差，报告边界带/内部与扩边前后差值；使用独立固定头比较概率，不把平滑程度直接当精度 |
| 少量标注是否有用 | 后续增加 1/3/5/10 正多边形检索；分类头另登记负例数、总标注面积/像元及校准成本，不把图块预算称为几个多边形 |

空间相邻像元不视为独立样本。保存逐空间块预测与混淆计数，按地理块配对 bootstrap 2,000 次，并配对支持种子，报告差值及 95% 区间。区间只描述该制品、抽样与区域条件；不能代替不同编码器训练种子的复现。小目标/道路子集属于机制分析，不替换主终点。

## 第二阶段：独立人工参考，验证真实边界与类别

- 已有 30 个 640 m 窗口，建筑/道路/水体共 90 项复核均为 pending；不是已有真值。增加绿地定义及标注项，必要时按预登记规则补充稀少类别，不能看预测挑窗口。
- 标注者独立判读同月影像，不显示模型预测；云影、配准和时相不确定区域标 ignore，部分样区双人复核。先确认道路是否含田间小路；绿地的植被覆盖与公园用地口径不得混用。
- 支持、校准、最终评价窗口地理隔离；最终标签不用于调参。初始30窗口仅作可行性起点，检查地理聚类/类别覆盖和区间宽度后在查看模型优劣前登记最终抽样规模。
- 已有窗口按 OSM 分层选取；分层成绩单列。只有取得入样概率/适当面积权重，才报告全域面积代表性精度。该数据仍是海淀区域内产品精度，不消除旧 P10C 的编码器区域见过性。
- 可称“总体更好”的条件：主终点配对差值为正且不确定性支持该方向；宣称边界改善还必须有边界指标支持，并披露各类退步。若仅建筑更好，结论只写建筑优势；不为了获得显著结果反复换类别、样本或阈值。

## 第三阶段：确认优势后才做最小归因训练

不重训完整历史流水线。全部从同一个 B0 checkpoint、相同空间划分出发，保持逐月高分输入、损失/监督来源、公共头处理、有效 batch、优化更新数及权重选择规则一致，冻结或解冻作为显式变量。

| 对照 | 用途 |
|---|---|
| C0：B0 仅公开源，继续训练 | 排除单纯额外更新带来的收益 |
| C1：逐月卷积末端融合，主干允许更新 | 检验旧式空间融合与共同优化是否值得恢复；不是完整历史 P10C 复刻 |
| C2：逐月 Transformer，主干冻结 | 优先复用此次 600 Epoch 记录，若协议不完全相同则只作历史参照 |
| C3：与 C2 完全相同但主干允许更新 | C3−C2 检验冻结约束；C3−C1 检验融合方案；C1/C3−C0 检验新增高分总体收益 |

全参数组的共享模块使用相同学习率规则，新模块也用相同规则；旧重建头/语义头是否更新必须统一登记，不能在 C2/C3 同时改变。按更新数和已见样本量匹配，不只匹配 Epoch；另报告设备时和参数量。首轮一个种子，出现稳定开发收益后才补两个配对种子。若两条融合路线仍只有重建收益，再单独检验高分尺度/结构监督，避免一次改多项。

## 可用材料与执行顺序

- 权重、逐月影像、两模型嵌入、B0 空间划分、下游头和预测已在本地；高分 Transformer 600轮训练/导出/四类评测完整。
- 已实现：F1、IoU、AP、10/20 m 边界 F1。待实现/验证：统一扩边导出、多个支持种子接口、Boundary IoU、空间块不确定性和道路结构统计。
- 缺失：独立人工真值；绿地口径、细路口径；旧初始化完整累计训练预算。
- 顺序：导出与接缝核查 → 配对 OSM 开发评测 → 人工独立参考 → 必要的控制训练。保留原制品、配置、样本清单、逐块结果和失败案例。
