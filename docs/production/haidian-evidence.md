# 海淀评测证据摘要

以下数值来自旧生产线已登记的固定海淀划分，阈值在 validation 选择、test 报告。这里只保留可
审计摘要，不迁入论文矩阵、展示素材或大图。

## Few-shot 最佳 F1

shot 表示正样本 patch 数，并配同数负样本 patch；validation/test 保持不变。

| 道路 | 50 | 0.517 | 0.501 | +3.3% |

这些结果支持“少量标注下更易读出”的海淀结论，不支持无条件跨城或全国泛化。完整监督时，原始
多源影像配强头可以达到或超过 embedding 配轻头，因此不应只引用 AUC 或只展示 PCA。
