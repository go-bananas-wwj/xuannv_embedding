# V5 数据操作细则

## B3/B6：高分资格与年度候选索引实际入口（2026-09-14）

新增统一入口 `xuannv data prepare-v5 --stage highres-eligibility`，除通用四根目录
外必须传 `--sensor-family` 和不可变 `--quality-root`；可传
`--alignment-audit-root` 引用既有波段审核（吉林一号允许逐条证明后跨快照继承，
细则见后文）。缺少审核时记录not_audited，
不以缺少精配准结果阻断整个候选目录。入口按来源族隔离写锁，不修改影像或质量掩膜。

输入为固定全国网格、已封存QA/来源目录、可选的审核输入/输出锁。逐项校验文件
SHA、来源族、QA快照一致性、观测身份/空间划分/年份。登记每个原生分支的路径、
文件SHA、采集日期、波段与有效像元计数；物理读取仍使用公共读取器，后续加载
再次验证实际源像元/掩膜。索引本身是封存元数据的资格审核，不冒称重新解码全量像元。

输出位于新数据目录 `observations/index/highres/<family>/<fingerprint>/`：

- `inputs.lock.json`：源/QA/审核文件、代码、运行库和选择规则指纹。
- `branches.parquet`：每个分支一行，保留所有候选及排除记录。低于60%仍保留清晰
  像元；部分缺失波段列出usable_band_ids，其余波段仍无效。已测得波段内部超限
  的场景保守排除其QA依赖分支，原因native_spectral_over_limit。
- `scene_groups.parquet`：场景全部分支与合格分支列表。只要有合格分支才有available。
- `annual_highres_candidates.parquet`：所有合格年度场景，全部继承原split，服务同年
  四季度。排名指标明确定义为合格分支中最大晴空比例，不声称这是跨分支面积并集。
- `annual_highres_default_selection.parquet`：每位置/年/来源族最多4场景，先覆盖不同
  季度，再按上述比例、日期、场景ID确定性排序。候选池单独保留，未作跨年替代。
- `summary.json`、`output.lock.json`：状态/排除原因/按年划分覆盖及所有输出封存。

原生波段审核的passed、uncertain、over_limit单独保存；它们都不能冒充绝对或
跨分辨率审核。当前没有该类通过证据，因此alignment_status=unknown、offset_m及
confidence为空，strict_pixel_fusion_candidate=false。tolerant_reconstruction_candidate
只表示可提交复核的几何/QA候选，不等于模型融合、云真值或用户验收通过。

重复运行核对来源、代码和已发布文件校验，不重写有效正式输出；输入版本变化
生成新目录。已有QA统计没有自动批准给新候选视图使用，须据新排除规则重算或
重新核对对应训练统计。基础影像物理合同仍缺证，当前入口先完成高分年度部分，
最终含基础月度观测的全国季度样本和B7/C1仍待完成。

## 最新方向：几何审核＋容忍平移的重建损失（2026-09-14，用户补充）

本节更新此前将逐观测≤5米精配准作为通用融合前置条件的安排。完整数据准备和
用户验收边界保持；减少反复标定/全量精配准投入，优先下载、合同、QA、标签、
统计、样本索引和加载。已有配准结果/失败证据原样保留，不能将不确定改成已通过。

原始依据为 [AEF论文v2表S2及S16.2.3](https://arxiv.org/html/2507.22291v2#S16.SS2.SSS3)：
S1/S2使用20米平移容忍的L1重建损失，Landsat使用30米面积平均重网格后的L1。
论文描述在允许平面平移中取最小误差，且使用逐帧/逐像元有效权重。下述窗口、
共享偏移和掩膜比较规则是本项目明确选择，不冒称论文公开了这些实现细节。

**数据阶段规则（已实施入口和当前快照见上节）**：

1. 保留全量CRS、仿射变换、1280米范围、patch_id/空间划分、年份、解码和QA检查。
   明显错位置、错误投影、旋转/尺度异常继续隔离；缩放/波段合同未知仍不能放行。
2. 精配准改为传感器、年份、地区、有效覆盖分层抽样和异常复核，不再要求全国
   每张图都成功测到亚像素偏移。已有全量审核作为诊断使用，不重复运行以追求
   全部passed。CFOG候选不再是完成数据主流程的必经步骤。
3. 新索引保存原alignment_status、offset_m、confidence、audit_scope及拒绝原因；
   strict_pixel_fusion视图仍需可靠≤5米证据。另建待验收的tolerant_reconstruction
   候选视图，合格几何/QA且精配准不确定的记录可以保留，但标注alignment_unknown，
   不声称偏移已知≤10米，也不自动授权原始通道逐像元叠加或边界精细监督。
4. 已证实大偏移、局部形变或波段内部错位不能靠一个整景平移损失消除，单列异常。
   云模型输入依赖红/绿/NIR空间一致性；此类源先禁用受影响分支及依赖QA，或建立
   专项修正版本。通过重建损失只代表目标误差有容忍性，不证明输入融合已对齐。
5. 候选索引、质量视图和统计来源需重新锁版本；交付报告分别给出可用候选、严格
   合格、已证实异常、无法判断的数量。允许无法判断随数据交付呈现，不能把它写成
   检查通过。数据验收不再以所有观测均精配准通过为条件。

**验收后损失实现合同（当前不修改训练代码或运行优化器）**：

- 以每个重建观测为单位，先产生一次预测，再比较允许范围内的平移。每个位移在
  空间及有效波段上计算平均L1，然后取最小值；同一观测各波段共享位移。不同观测
  可以不同，不按像元各自寻找最有利邻居；同景跨分辨率联合计算时共享物理位移。
- 用米配置容忍范围，依据重建损失网格的真实分辨率换算。吉林一号5米网格先比较
  欧氏半径0/5/10米；整数候选分别为1/5/13个。若采用每轴±2像素的25个方形候选，
  对角线实际可达14.14米，必须显式声明，不能标成10米半径。特征图像素不等于原图像素。
- 枚举位移前确定共同有效比较区域；原始NoData、云/影、缺失波段同步参与掩膜。
  所有候选使用同一支持区域与归一化分母，防止通过避开难像元获得更低loss。
  无共同有效区域的观测不参与该项损失并计数，不能伪造为重建完美。
- min放在每个观测的空间/波段聚合之后、batch聚合之前；反向传播使用获胜分支。
  并列时优先零偏移，再按位移距离和固定坐标顺序确定。边缘裁剪、不循环回卷；
  记录最优位移分布、搜索边界命中比例和有效覆盖，追踪模型是否靠错位降低损失。
- 第一版仅容忍重建目标的平移。精确标签、道路边界、变化监督及正式评测仍保持
  原坐标；容错损失不能扩大到所有任务以掩盖空间精度损失。年度先验保留同年限制。
- 单次编码/解码后对张量裁剪比较，不对每个位移重跑Transformer。减少的是离线
  精配准工作，训练损失比较会增加；需实际测吞吐、内存和下游效果，当前不承诺倍速。
- 先测试已知整数/半像素错位、零偏移回归、云/NoData、全无效、波段共享位移、
  搜索边缘和小地物误配；验收后的固定训练子集比较0/5/10米，检查少样本宏F1、
  边界与变化表现，不能只依据容错重建loss下降选型。

当前代码中的重建损失仍为固定坐标掩膜L1；本次只调整数据工作优先级及记录后续
模型合同，未宣称容错损失已实现或模型收益已验证。无需继续为本轮GF6的两个
不确定标定案例阻塞数据准备；它们保留为严格审核诊断，不降阈值、不抹去失败。

## B3：CFOG结构特征候选及冻结标定

   输出quarter_samples、annual_highres_candidates、annual_highres_default_selection。

   掩膜、缺月/仅雷达/无高分/部分分支/全云；原始与缓存一致，重复运行有效跳过、
   源指纹改变拒用旧产物。输出loader_verification、reproducibility_checks和dataset.lock。

```python
"""Deployment launcher only; source locking, transfers and retries belong to xuannv."""
import datetime
import fcntl
import json
import os
from pathlib import Path
import subprocess
import sys

root = Path(__file__).resolve().parent
config = json.loads((root / 'download_background.config.json').read_text())
report = Path(config['report_root'])
marker = report / 'download_worker.json'


def inspect():
    saved = json.loads(marker.read_text()) if marker.exists() else {}
    pid = saved.get('pid')
    try:
        parts = Path(f'/proc/{pid}/stat').read_text().rsplit(')', 1)[1].split()
        identity = f'{pid}:{parts[19]}'
        if identity != saved.get('identity') or parts[0] == 'Z':
            return None
        args = Path(f'/proc/{pid}/cmdline').read_bytes().decode().strip('\0').split('\0')
        if args[args.index('--stage') + 1] != 'ingest':
            raise RuntimeError('recorded process is not an ingest worker')
        if args[args.index('--source-root') + 1] != config['source_root']:
            raise RuntimeError('recorded process uses a different source root')
        if args[args.index('--download-route') + 1] != 'direct':
            raise RuntimeError('recorded process is not using the direct route')
        return {'pid': pid, 'identity': identity, 'state': parts[0],
                'session_id': int(parts[3]), 'independent_session': int(parts[3]) == pid}
    except FileNotFoundError:
        return None


def status():
    progress_file = report / 'acquisition_progress.json'
    progress = json.loads(progress_file.read_text()) if progress_file.exists() else {}
    return {'worker': inspect(), 'progress_status': progress.get('status'),
            'downloaded_archives': progress.get('downloaded_archives'),
            'validated_archives': progress.get('validated_archives'),
            'downloading_pair': progress.get('downloading_pair', []),
            'failures': progress.get('failures', []), 'download_route': 'direct',
            'training_authorized': False}


if len(sys.argv) != 2 or sys.argv[1] not in ['start', 'status']:
    raise SystemExit('usage: download_background.sh start|status')
if sys.argv[1] == 'start':
    # Serialize launch attempts. The CLI independently owns its existing data writer lock.
    with (report / '.background-download-launch.lock').open('a') as launch_lock:
        fcntl.flock(launch_lock, fcntl.LOCK_EX | fcntl.LOCK_NB)
        if inspect() is None:
            with (Path(config['source_root']) / '.prepare.lock').open('a') as data_lock:
                fcntl.flock(data_lock, fcntl.LOCK_EX | fcntl.LOCK_NB)
            args = [config['python'], '-m', 'xuannv_embedding.cli', 'data', 'prepare-v5',
                    '--stage', 'ingest', '--download-route', 'direct']
            for key in ['source_root', 'dataset_root', 'report_root', 'base_root']:
                args += ['--' + key.replace('_', '-'), config[key]]
            env = dict(os.environ)
            env.update(PYTHONPATH=str(Path(config['checkout']) / 'src'),
                       LD_PRELOAD=config['preload'], OMP_NUM_THREADS='1',
                       OPENBLAS_NUM_THREADS='1', MKL_NUM_THREADS='1')
            for key in ['NO_PROXY', 'no_proxy']:
                env[key] = ','.join(filter(None, [env.get(key, ''), 'modelscope.cn', '.modelscope.cn']))
            with (report / 'download_background.log').open('ab') as log:
                child = subprocess.Popen(args, cwd=config['checkout'], env=env,
                                         stdin=subprocess.DEVNULL, stdout=log,
                                         stderr=subprocess.STDOUT, start_new_session=True)
            parts = Path(f'/proc/{child.pid}/stat').read_text().rsplit(')', 1)[1].split()
            saved = {'pid': child.pid, 'identity': f'{child.pid}:{parts[19]}',
                     'started_at': datetime.datetime.now(datetime.timezone.utc).isoformat(),
                     'download_route': 'direct', 'training_authorized': False}
            temporary = marker.with_suffix('.tmp')
            temporary.write_text(json.dumps(saved, indent=2) + '\n')
            temporary.replace(marker)
print(json.dumps(status(), ensure_ascii=False, indent=2))
```
