# 固定表征与传统分类器比较

只训练下游头，不训练编码器。xuannv与原始特征使用同一六个月公开观测及静态汇聚
高分光学/SAR输入；官方AlphaEarth使用2025年年度COG。本轮不加入DINOv3。
B0的既有评价保留，但其未标准化、固定正则协议不能直接当作本轮同协议排名。

## 协议

三种表征均运行Ridge的1/5/10完整支持图块预算；五图块额外运行随机森林和RBF-SVM。
八项OSM任务、六项ESRI一对其余任务，各三次嵌套抽样；总计630个最终选定配置。
共用空间划分、支持像元、标签及有效域。正负各最多4096个支持像元。
StandardScaler只拟合抽中的支持像元，不读取验证或测试统计量。

Ridge alpha按10/1/0.1评测，SVM C按0.1/1/10、gamma=scale；参数仅按验证AP选取，
1e-12内并列选择更强正则。RF固定200棵树、sqrt特征、叶节点至少2样本。
所有头采用类别平衡权重；阈值仅按验证F1确定。SVM用等价的分块RBF矩阵计算，
三个C共享验证核计算，与sklearn标准输出有数值回归测试。

OSM与上游监督关联；ESRI是2023年机器制图产品，建成区不是建筑轮廓。
ESRI只在唯一有效类别区域做一对其余评测，不能称为2026年独立人工真值。
两类标签分别汇总；AP、F1及IoU均提供2000次配对图块bootstrap区间。
AP在每次重采样后的全部像元排序上精确重算，分数并列作为同一阈值处理，
无正类的重采样AP记为0；Numba只加速计数，不改变指标或减少重采样次数。

## 官方数据修正

复查历史源码发现：旧官方嵌入缓存对编码整数做插值后再反量化。两种运算不交换。
本轮校验原COG摘要、A00--A63顺序、int8和-128无效值后，先按官方公式反量化，
再在浮点向量上重投影，最后单位化。历史缓存留存，不用于本轮分类。

## 接口与审计

`xuannv audit compare-prepare --spec <json>`：校验输入，生成64/64/150维特征、共同有效域和标签。
`xuannv audit compare-run --spec <json>`：最多四进程，每任务最多四线程；按输入摘要断点续跑。
`xuannv audit compare-report --spec <json>`：生成任务、预算、分类器、固定位置案例四组图和数值表。

配置字段为output、source_audit、alphaearth、seeds、budgets、workers、threads。
原始数据、预测、头、日志放在仓库外；代码、文档、小型结果与论文图表分步提交。
保存每个最终头、支持像元、标准化参数、候选验证AP、阈值、预测及哈希。
示例位置在拟合前按参考标签与固定散列指定，不根据方法胜负替换。

## CPU 核计算与计时

RBF核保持float64，将距离、截断和指数操作融合为NumExpr表达式，最多四线程。
原始NumPy版本与融合版本在全部11个已完成SVM头的抽查像元上逐值相同，
并与sklearn标准预测一致；分类器、支持位置、参数与阈值规则均不变。
已完成结果保留原实现摘要，新结果额外记录kernel_backend；仅允许复用经过
该等价检查的指定旧实现摘要，不放宽输入或配置校验。成本表只汇总融合CPU
版本的SVM计时，给出实际计时样本数，避免混用不同计算实现的速度。
