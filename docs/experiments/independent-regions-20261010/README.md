# 两区域独立训练与论文复现

本文在每个地区固定一个最终模型，各任务共用六个月平均64维嵌入。
海淀仅用海淀观测和地图训练；哈尔滨仅用当地资料训练，不从海淀或联合区域权重初始化。
两地使用相同核心网络，不承诺优化配方、质量处理或导出精度完全一致。

## 文件与结果

- [summary.json](summary.json)：最终权重SHA-256、源代码版本、全区分类平均结果及范围。
- [paired-metrics.csv](paired-metrics.csv)：900条已完成的最终模型对照记录，包含校准与全区、
  AEF与Raw180、分类F1、检索AP及比例RMSE；退步结果同样保留。
- [区域A配置](../../../configs/examples/independent_region_a.yaml)：海淀最终联合更新的父配置模板。
- [区域B配置](../../../configs/examples/independent_region_b.yaml)：哈尔滨最终当地继续训练配置模板。

模板将机器路径替换为`/data/region_a`与`/data/region_b`，不是原运行配置的逐字复制；
配置/缓存/权重哈希须按实际复现输入重新登记。海淀模板需要静态标签sidecar和
`regional-static-refinement-v1`配方，不能用普通`train`命令代替最终联合更新。
哈尔滨使用`regional-base-v1`严格配方和当地父权重。缺少影像/标签/权重的公开代码仓不能
单独重现评分；本目录不分发私人观测，也不下载未授权资料。

## 执行顺序

1. 按各区域配置准备本地影像、逐月有效标记、OSM监督和ESA WorldCover 2021 v200标签。
   所有缓存和输出位于仓库外。先核对图块身份、投影、边界、月份与源通道，再计算哈希。
2. 分别登记训练配方。区域A使用`xuannv experiment refine-region`；区域B使用
   `xuannv experiment regional-base --spec /data/region_b/spec.json --phase validate`验证，
   按硬件几何登记approval后以`--phase train`执行。父权重属于对应当地训练。
3. 冻结编码器导出逐月64维嵌入并逐维求平均。区域A使用
   `xuannv experiment export-refinement`；区域B按`build_regional_system`和配置重建系统，
   严格消费最终checkpoint，使用全部可用观测。两个导出的数值约定见下文。
4. 登记`full-region-data-v1`数据和`full-region-readout-v1`任务。三种表示必须在任务内共享
   地理身份、标签、有效域、支持位置和校准位置，分别拟合各自的下游头。
5. 对每个任务先运行`xuannv experiment full-region-readout --spec JOB.json --phase calibration`，
   再用同一spec执行`--phase full_region`。全区阶段复用校准阶段已保存的头与阈值，不再次拟合。
6. 对四种分类器、5/20图块预算先求任务平均，再将八组等权平均。
   检索使用三个连通斑块样例；比例估计使用五个支持图块。单位和负结果保留。

训练命令入口及配方合同见[静态更新](../../regional-static-refinement.md)、
[训练与导出](../../training-export-downstream.md)和[全区读取](../../full-region-readouts.md)。
公共仓库同时保留历史实验模块，支持U-Net等读取并不表示本轮八组主比较包含这些方法。

## 已完成的实验条件

海淀：320训练和评分图块；2025年12月至2026年5月；最终静态监督系数0.25，
固定末月细语义头；最终阶段6张NPU、每卡2样本、累积4、有效批量48、800次成功更新。
静态头先单独拟合，随后联合更新；具体阶段预算以原配方为准。
哈尔滨：422训练图块、348核心相交评分图块；2025年5月至10月；
从当地scratch父模型继续800次成功更新；静态监督系数0.50，细语义作用于时间平均，
3张NPU、每卡4样本、累积4、有效批量48。公开与高分学习率1e-5，头1e-4，预热20次，
权重衰减0.05、种子41。运行控制器等待进程完成再进入导出和评测，无需高频聊天轮询。

海淀月度float32，以float64累积后保存float32均值；哈尔滨月度float16，
转换float32后平均。均值向量不重新归一化。输出空间网格为10米。
哈尔滨S2/Landsat质量载体通道置零并从连续重建中排除；高分资料无完整云质量标记。
模型配置中历史目标名`worldcover`对应OSM合并地类；独立ESA目标与该历史别名分开登记，
不得误认为使用AEF嵌入蒸馏。

## 评价范围

海淀10项、哈尔滨15项任务不同，只在各自区域内比较表示。原始180维对照包含五类观测，
其中包含地方高分光学和SAR；四类读取器均有匹配的传统或神经网络对照。
AEF为官方2025年度64维特征，观测时段与本地模型不同。
OSM和WorldCover参与上游监督；哈尔滨Dynamic World 2025第三季度只用于下游参考。
全区评分包括上游训练、下游支持和校准位置，描述区域制图一致性，不是独立空间盲测。

海淀历史候选选择使用过全区结果。哈尔滨最终选择依据完整校准汇总，锁定前部分全区
结果已可用，不称为完全未查看全区结果。单一训练种子和一次固定支持抽样不支持
显著性声明。分类平均提升也不表示每个地类、检索或比例估计均更好。

## 验证与保存

运行仓库规定的pytest、Black、Ruff、内容门禁和wheel构建；NPU与checkpoint的实际门禁记录
保存在仓库外。既有训练快照保持不变；此次整合训练与读取分支不会回写旧登记身份。
