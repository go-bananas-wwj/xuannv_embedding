# 固定权重多维评价（2026-09-21）

本轮执行用户确认的固定旧权重与 B0 产品评价，替代此前需要新增对照训练的计划。
不训练编码器、不扩大架构消融。论文称旧版表征为 xuannv；实验版本留在可追溯记录中。

## 已固定的协议

- 两权重：旧版 epoch800（继承早期基座继续优化），公开来源 B0 seed41 best epoch192。
- 沿用 B0 训练158、验证67、测试57、缓冲38的划分；旧权重上游覆盖全部320图块。
- 重新导出六个月，10 m网格扩边16像素后裁取128像素中心。源图块先映射到共同网格，
  从实际相邻图块取得上下文；覆盖外缺失输入填零。高分保持旧版静态有效观测汇聚方式。
- 建筑、道路、水体、绿地、林地、农田、裸地、教育用地；完整支持图块1/5/10，三种子
  20260916/17/18；Ridge alpha=1、类别平衡，每类最多4096像素；5图块另用余弦kNN k=5，
  每类最多1024像素。标签0为背景，不能按归档nodata=0剔除。
- 阈值只由验证集确定；测试块保存分数、混淆计数、AP及边界统计。三次抽样均值差异采用
  配对图块bootstrap 2000次。区间以固定模型和当前区域为条件，不反映跨区域泛化不确定性。
- 正类检索使用训练范围中8连通、至少4像素的标签斑块，按固定散列抽取1/3/5例，取归一化
  样例均值特征与查询的最大余弦相似度。不把这些斑块称作新增人工多边形。
- 语义分析使用ESRI六类参考，剔除重叠与未归类像素，每4×4格至多一例，每类最多1000例；
  原始64维计算cosine Silhouette及Euclidean Davies–Bouldin。报告各类实际数量。
- 小目标定义为8连通、至多25像素，排除被图块边缘截断者；检出要求覆盖其至少50%像素。
- 月度统计在同一批测试位置抽取512像素/图块；无变化真值，不把稳定等同于正确。
- 接缝指标为跨缝余弦距离与相邻内部距离的比值，只诊断上下文不连续，不当作制图精度。

## 运行入口与制品

统一入口为 `xuannv audit export/prepare/probe/describe/report --spec <spec.json>`。
`export`另需`--model`和`--device`，`probe`另需`--task`。本地路径由仓库外spec提供。
每个导出记录绑定权重、配置、缓存、空间范围和文件摘要；支持ID、像素抽样摘要、读出参数、
预测及指标分别保存。图表从这些结果生成，不按分数挑选类别；示例位置在预测前按标签固定。
NPU导出使用 `TASK_QUEUE_ENABLE=0`，避免当前运行环境的异步搬运停滞。

此比较不能分离高分输入、初始化及训练地域的作用。OSM关联结果不是独立真值评测。
数字表、正式图件及复现源进入中文论文，原始影像、模型、嵌入和运行日志不进入Git。
