# 海淀首轮实验对导师意见的逐项说明

2026-10-21。本文件整理现有证据及后续正文修改建议，尚未把这些建议写入
Overleaf。已完成训练、九组72条逐任务读出以及三套表示的全区冻结查询。
地图案例与缺测分析尚未完成，因此不把海淀案例登记为全部收尾。

1. 科学问题和创新机制要说清楚。

导师关心的是：地方影像不完整、采集时间不连续、空间尺度不同时，加入更多数据
为什么未必改善表示，所设计的方法具体改变了什么。正文应从这些观测条件出发，
说明融合过程如何使用实际日期、覆盖和视觉信息，而不是只说全球模型不能接入
地方影像。当前方案确实按实际采集期处理六份地方光学，最终输出统一64维表示。

需要区分两套实现：新训练原稿架构采用高分分支适配与联合更新；当前被选定用于
全区查询的是此前完整逐期融合方案。正式方法必须逐项对应后者的区域表示、
视觉预训练组件和末端引导代码，不能把原稿网络结构直接套到后者的分数上。
引言与相关工作的原有基础保留，在方法节补清实际范围和组成。

这项意见只得到部分回答。缺测条件下为何退化、覆盖控制是否起作用，仍需缺测
实验；使用外部预训练视觉模型和AnyUp也需明确归属，不能全部写成本文新机制。

2. 增加消融实验，量化模块贡献。

已经完成了简单拼接、DINO上下文特征、去额外几何、二值覆盖以及AEF使用同样
三种影像引导的比较。全部使用同一套任务、支持预算和校准位置。

当前校准结果如下，单位为四类平均F1百分比：

| 条件 | MLP | CNN |
| --- | ---: | ---: |
| 此前完整逐期融合 | 85.206 | 85.189 |
| 去掉额外几何补充 | 85.218 | 85.355 |
| 覆盖比例改为有/无标记 | 85.206 | 85.187 |
| 简单拼接融合 | 79.416 | 84.129 |
| DINO上下文特征 | 78.287 | 82.119 |
| AEF加地方高分引导 | 84.151 | 83.981 |

这些结果支持“直接拼接和单独视觉特征未达到完整方案的表现”。但额外几何分支
在海淀没有显示平均收益，去掉后CNN反而略高；连续覆盖权重与二值标记差别也
很小。正文不能把这些模块都写成已被验证的有效创新。AEF使用相同引导后并非
两种读出都提高，说明整体收益不能仅用通用引导算子来解释，也不能据此声称
本文每一项设计都有效。

新训练原稿高分版的校准平均F1为84.512、84.636，基础公共版为84.451、84.616。
相对公共版只有0.061、0.021个百分点；这组数据尚不足以支持明显的高分收益。
按原先条件，不追加该原稿分支的结构重训消融，后续围绕已选方法整理证据。

3. OSM以外的地表覆盖任务需要解释。

本阶段主评价采用未作为编码器训练目标的CLCD2025，包含耕地、林地、水体和
不透水面。训练仍使用WorldCover与OSM弱监督，不能称为完全无地类监督。
全部类别和两种读出分别保留，不只列改善类别。参考来自机器制图产品，应描述
为地类参考/制图一致性，避免直接等同于独立人工真值。

全区320图块、分类头与阈值固定时，Google AEF的MLP/CNN平均F1为83.214、83.260；
区域三源模型为83.843、84.211；此前完整融合方案为84.496、85.319。排除下游
支持和校准图块后，三者分别为82.745/82.498、83.506/83.578、84.011/84.794。
这说明完整方案在当前海淀地图任务上有平均优势。编码器在全区域训练过，此处
不是新区域的独立盲测，也不代表每类都超过AEF。

完整融合的全区CNN在耕地、水体、不透水面上相对AEF提高约6.61、1.51、0.41个
百分点，林地低约0.30个百分点。正文应把优势限定到实际支持的类别与范围。

4. 高分观测在10米表示里保留了什么细节？

现有匹配校准对照中，原生高分完整融合为85.206/85.189，降至10米信息的版本
为84.797/85.290。原生高分仅在MLP更高，CNN略低；不能据此概括为细节在全部
设置下都有收益。

CLCD参考网格约30米，不能直接证明2米或3米建筑轮廓、道路宽度得到恢复。
逐类分数和现有边界统计可以说明参考网格上的类别表现；更细的空间主张仍需
配准正确的场景图，以及来源和年份核实后的细粒度参考。场景图须区分不透水面
与建筑、观测分辨率与重采样网格。当前这项证据尚未补齐。

5. 研究定位：融合方法、稳定表示及实际复用。

现有海淀结果可支持的定位是：在区域数据和已有预训练组件条件下构建统一表示，
用固定嵌入服务多类制图，并报告相对官方AEF的区域任务效果。完整方案与新训
三源网络还存在预训练组件及训练目标差别，二者之间的差值不是高分数据单独
贡献；高分和模块作用必须引用对应方法内部的匹配消融。

这一点在同方法控制中尤为重要：此前逐期方案的公共条件为84.623/85.471，
高分条件为85.206/85.189，MLP提高、CNN降低。该条件作为对应方法的归因证据
保留，不因为退出主展示门槛而改写其结果。

新原稿架构这一轮训练循环合计约41.17 NPU卡时，未含数据准备、初始化、导出
和下游评分。这个数字不属于被选中的既有融合流水线，不能替换其全流程成本，
也不能与AEF全球预训练时长直接比较。完整方案的准备、视觉编码、区域拟合、
引导及下游成本仍需按实际来源记录汇总。

6. JAG专刊建议。

这是投稿方向建议，不是已经完成的投稿安排。当前先把海淀的方法归属、匹配
消融、缺测和细节证据讲清楚；具体专刊主题、范围和截止时间另行核实。

目前只允许写“海淀已有区域制图优势及部分机制对照”，不能写“三个区域均已
验证”。哈尔滨新区与奥克兰西部保持停止，Overleaf正文尚未修改。
