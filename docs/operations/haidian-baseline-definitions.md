# 海淀基线定义与全区结果

更新于北京时间 2026-10-20 20:02。

## 三个名称分别指什么

| 展示名称 | 编码器/权重来源 | 本轮如何使用 |
| --- | --- | --- |
| Google AEF官方嵌入 | 官方全球预训练模型生成的2025年度64维产品 | 下载已有向量，未在本地重训官方编码器；拟合同条件下游头 |
| 区域三源模型（无地方高分） | 本项目自行在海淀全部320个图块上训练 | S2十一波段、S1两极化、Landsat六波段；2025年6月—2026年5月十二个月；平均为64维 |
| 区域高分模型（本次原稿重训） | 同一个公共底座加地方光学分支 | 共同公共数据和弱监督，另加六份实际地方光学观测 |

“区域三源模型”仍有真实ESA WorldCover2021和OSM辅助监督，以及影像重建和均匀性目标。公共指影像来源，不代表未经训练或没有地类监督。CLCD2025没有作为编码器训练目标。该三源模型未读取AEF向量，也未读取地方高分、DINO或AnyUp。

项目内部AEFModel是本地实现的类名，不能据此把其权重称为Google官方AEF或官方模型的严格复现。为避免混淆，展示时使用上述三个名称，保留已有内部实验ID以维持来源记录。

此前完整融合方案是另一套已经登记的区域表示、视觉预训练特征与逐期引导流水线；它的成绩与本次原稿高分重训成绩分别归属，不能互相替换。

## 为什么区域三源模型可能高于AEF

AEF原论文的Composites基线是直接合成影像得到的16维特征，和本地经过训练、带弱监督的64维网络不同。官方论文在其指定基准和协议上的结果不保证任意新区域、类别组合和分类器设置都维持同样排名。原文见[S19.2.1及评测设置](https://arxiv.org/html/2507.22291v1)。

本地专门训练、WorldCover/OSM监督、额外2026年观测以及MLP/CNN读出设置均可能影响本次排名；这些是解释假设，尚未用成对消融分离各因素。AEF年度2025与本地2025年6月—2026年5月也不能写成相同观测窗口。

## 全区320图块的冻结读出结果

这些分数使用原分类头及阈值，与此前用于方案选择的固定校准位置分数分开报告。全部有效范围包含下游支持和校准图块；另外给出排除这些图块的结果。编码器在区域全体图块上训练，下面不是新的独立区域盲测。

| 方法 | 全区MLP F1（%） | 全区CNN F1（%） |
| --- | ---: | ---: |
| Google AEF官方嵌入 | 83.214 | 83.260 |
| 区域三源模型（无地方高分） | 83.843 | 84.211 |
| 此前完整融合方案 | 84.496 | 85.319 |

| 方法 | 排除下游支持/校准图块后MLP F1（%） | 对应CNN F1（%） |
| --- | ---: | ---: |
| Google AEF官方嵌入 | 82.745 | 82.498 |
| 区域三源模型（无地方高分） | 83.506 | 83.578 |
| 此前完整融合方案 | 84.011 | 84.794 |

完整方案与区域三源模型之间的差值包含整套训练、预训练组件和融合的区别，不能全部归因于增加高分数据。单独高分和融合模块贡献仍依靠对应方法内部的匹配消融。

主表可以突出完整方案对AEF的实际优势，消融表如实报告无高分条件。额外传统基线须按原始影像统计特征、RF/MLP等明确方法定义正常评测，不为扩大差距去破坏已训练表示、单独减少训练或更改标签。
