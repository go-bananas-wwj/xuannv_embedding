# 海淀先行：按导师意见完成一个区域的证据

2026-10-20 用户调整顺序：停止本轮所有三区训练及接续调度，先完成海淀案例，
再扩展哈尔滨新区、奥克兰西部。此指示取代此前的三区同时训练安排；原始科学
问题、同条件对照和结果保留要求继续适用。其他区域的断点和资料保留。

## 本阶段先形成什么

| 导师意见 | 海淀对应证据 |
| --- | --- |
| 说清楚不完整覆盖、非连续时间、跨分辨率导致的问题 | 按实际观测期和覆盖分布描述输入，检查融合前后的表示及误差分布 |
| 收益来自方法还是更多高分数据 | 同配方公共版、高分版、简单拼接、DINO 特征、相同引导增强的 AEF |
| 量化各模块贡献 | 无几何补充、二值覆盖、无末端引导、先平均再引导；重训架构的窗口读取、公共保留和降质训练按原计划接续 |
| 解释 OSM 以外的表现 | CLCD2025 四类，MLP/CNN 分列逐任务 F1/IoU/AP，完整保留强公共参考及下降结果 |
| 说明高分细节进入10米嵌入后的贡献 | 原生/降质输入、边界/内部结果及固定位置案例；图示尺度遵循真实数据网格 |
| 固定嵌入复用及研究定位 | 同一嵌入服务所有地类，报告一次编码、下游拟合的实际成本；已有细粒度标签核对来源后再复用 |

本轮先训练一个公共底座，再从共同底座形成公共版和高分版两份终版模型。
底座2400次更新，两个分支各1600次；高分分支先800次适配再800次联合更新。
全区320图块、十二个月公共三源、六份实际地方光学观测、真实 WorldCover 与 OSM
弱监督、六层骨干、64维平均嵌入和种子41均沿用原计划。

为加速单区，底座集中使用六张卡，公共分支使用两张卡，高分分支使用四张卡。
每卡微批量4，通过累积保持每次更新总样本48。第七张卡先处理简单融合和
DINO 特征等较快对照，再运行影像引导对照。设备0上的无关服务不变。
此前两卡底座仅到70/2400，权重另行保留；六卡底座使用独立登记的新输出从头
学习，不改写旧断点的进程身份。不能把并行度变化称为新的模型贡献。

首轮共有9种新评分条件、72条逐任务/分类头结果；AEF、历史更强公共参考及
已完成的同一特征对照经身份核对后复用。采样位置、支持预算、下游头更新次数
和阈值规则保持不变。先取得海淀的完整模型和机制比较，再决定需继续完成的
结构消融、细节及应用图。海淀通过两个分类头和区域均值要求，仅表示海淀阶段
达标；三区共同方法是否有效仍待另外两区，不能提前给出三区结论。
