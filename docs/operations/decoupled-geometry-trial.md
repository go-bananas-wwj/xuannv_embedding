# Separate coarse public semantics from local detail learning

The gated spatial study completed eighteen fits, thirty-six readers and all240
conditions. Its independent persisted-prediction audit passed, but neither common
candidate met accuracy acceptance. The better worst-slot candidate still trails
the stronger AEF/public reference by3.1187 percentage points in its weakest slot.
No full query or Overleaf success claim followed. All results and weights remain.

The spatial correction was active and its RMS exceeded original hidden features
in observed diagnostic tiles. Routes after this shared mixer can carry public
features, so a context gate is not causal evidence of local-data contribution.
Geometry retention reduced its training error but did not repair primary scores.
These findings motivate the next test; they do not establish a causal explanation.

architecture. WorldCover/OSM semantic heads consume only the learned public branch.

representation fitting. Genuine-public/degraded controls remain matched.
