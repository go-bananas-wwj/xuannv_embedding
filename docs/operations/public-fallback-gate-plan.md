# Give the gate an explicit public fallback and adapt its weak heads

The preceding bounded gate failed the complete three-region primary acceptance.
Keep all negative task records and the same public reference envelope. The next
registered test addresses two observed limitations as one staged design: routing
has no explicit public-only expert, and fixed semantic heads may favour the source
on which they were trained. These are hypotheses, not controlled causal findings.

Add one genuine-public expert from the same completed time-modulated algorithm in
every region. It ranks closest among thirteen completed common public algorithms
using the current worst-six-slot comparison; it is not chosen separately by city
or reader. Its three existing outputs have passed shared public-anchor, index,
public/physical normalization and weak-source-reference checks against the semantic
source. Full genuine-public lineage and payload checks remain required before fits.
The semantic and geometry experts stay matched to each native/public/degraded role.
All three source encoders and source feature arrays remain frozen.

Predict three softmax weights per channel and pixel. Two 3x3 convolution,
GroupNorm and GELU blocks of width 32 consume 638 channels: the clipped public
anchor, three source corrections and three absolute pairwise correction differences,
plus the observed physical statistics and their mask. A zero 1x1 projection emits
192 logits, reshaped into three 64D weight maps. Initial weights are 0.05 for the
public expert, 0.8075 for the semantic expert and 0.1425 for geometry. Output
coordinates remain convex mixtures of these three values; public information can
be selected explicitly where private corrections are unhelpful.

Initialize weak heads from the semantic source, then allow them to learn. Hold
mixture weights constant for 200 head-only updates so the heads can adapt to the
initial representation. Jointly train the gate and auxiliary heads thereafter.
Normalizers and all source encoders remain fixed. Head inputs retain the original
clipped-anchor contract. WorldCover/OSM weights, unknown-label handling and physical
domain remain unchanged. The only two common cases penalize standardized movement
from the initial three-expert mixture with weights 0.2 or 1.0. No primary CLCD,
Dynamic World or LCDB labels, or AEF values, enter representation fitting.

Both cases use 2,000 updates, learning rate 0.0003, weight decay 0.01, clipping 1,
seed 41, 100 learning-rate warm-up updates and the same cosine floor. Select one
batch from 64/128/256 by predeclared joint-stage throughput and a 54 GiB allocation
limit. Benchmark only after the head-warm-up and ten joint warm-up updates, then
time ten joint updates. A full 422-tile selected-batch recovery check must cross
update 200 into update 210; early head-only memory is not sufficient evidence.
